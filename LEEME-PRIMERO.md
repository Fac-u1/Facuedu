# Facuedu.uy AYUDA Navegadore 1.1.0 — todo en un solo proyecto

Orden de pasos:
1. Supabase: ejecutá `supabase.sql` y desplegá `supabase/functions/aprobar-login`.
2. Netlify: subí la carpeta `web-telefono/` (la dirección ya está en `config.js`).
3. Probar en la computadora: `npm install` y después `npm start`.
4. Mac firmada: cargá los secretos de la sección de firma en el README, subí el proyecto a GitHub y corré el workflow "Build macOS (firmado y notarizado)".

Ver README.md para los detalles y para la lista de pruebas a mano.
